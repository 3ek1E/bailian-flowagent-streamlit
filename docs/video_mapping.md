# 视频与实现对应

视频：[《20 行代码彻底搞懂小龙虾！》](https://www.bilibili.com/video/BV19hwTzwETF/)，飞天闪客，搜索索引显示发布于 2026-03-15。

访问限制：本次 B 站页面与公开元数据请求返回 412，未能观看完整视频或取得作者原始代码。标题由 B 站搜索结果确认；原理另参考[同作者抖音发布页](https://jingxuan.douyin.com/m/video/7617381645494095130)。本实现是教学原理的独立重写，不能宣称逐行还原视频或完整复现所有镜头。

| 视频展示的主线 | 本仓库对应 |
|---|---|
| 先调用大模型 API | `bailian_client.py` 调用已发布的 Agent 1.0 应用 |
| 给模型说明可执行的命令 | `PROTOCOL` 与云端系统提示词 |
| 判断回复，执行后继续循环 | `mini_agent.py` 精简主循环 |
| 把执行结果反馈给模型 | `run_agent` 工具观察回传 |
| 加网页完成交互 | `app.py` 的 Streamlit 对话页 |
| shell 可执行本机操作 | 显式 `--allow-shell` 或网页开关 |

适配作业要求的变化：将通用大模型接口替换成百炼 Agent 1.0；将自由文本命令识别替换成 JSON 动作；默认提供有路径限制的文件工具；用 Streamlit 服务作为网页和本地执行进程，无需另写 HTTP 服务。

视频涉及的下载示例可以在用户安装相应下载工具、拥有访问权限并启用 shell 后尝试；本次没有下载视频，也没有声称该外部任务已经验证。社会软件接入、定时任务和长期记忆不在当前实现中。
